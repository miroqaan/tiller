턴이 도는 중에 보낸 메시지는 **눈에 보이는 대기열**에 들어간다. 나가기 전까지 고치고, 순서를 바꾸고, 합칠 수 있다. **Tab**은 지금 도는 턴을 끊지 않고 그 턴에 끼워 넣는다. 하던 작업은 그대로 두고 방금 들은 말을 반영해 이어 간다.

![대기열에 후속 메시지 둘을 넣고, 하나를 고쳐 위 항목에 합친 뒤, Tab으로 바로 보내고 답변이 끝나자 대기 메시지가 나가는 화면](docs/queue-steer.gif)

## 왜 만들었나

Claude Code CLI와 공식 데스크톱 앱은 에이전트가 바쁠 때 보낸 메시지를 둘 중 하나로 처리한다. 보이지 않는 대기열에 넣거나, 그 자리에서 턴을 끊거나. 무엇이 대기 중인지 보거나, 고치거나, 순서를 바꾸거나, 하나만 먼저 보낼 방법이 없다.

같은 요청이 Claude Code 이슈 트래커에 계속 올라온다.

- [anthropics/claude-code#92988](https://github.com/anthropics/claude-code/issues/92988) — 데스크톱 Code 탭에 "턴이 끝날 때까지 대기"가 없다
- [anthropics/claude-code#77537](https://github.com/anthropics/claude-code/issues/77537) — 대기열 UI: 항목을 보고, 지우고, 하나씩 넣기
- [anthropics/claude-code#30492](https://github.com/anthropics/claude-code/issues/30492) — 도구 호출 사이의 실시간 조종

tiller는 그 빈자리를 메우는 프런트엔드다. 에이전트를 대체하지 않고, 이미 쓰던 에이전트를 운전한다.

## 대기와 조종

| 키 | 대기 중 | 에이전트 작업 중 |
|---|---|---|
| Enter | 전송 | **대기열에 추가** |
| Tab | 전송 | **도는 턴에 끼워 넣기(조종)** |
| Shift+Enter | 줄바꿈 | 줄바꿈 |
| Esc (입력창이 빈 상태) | — | 지금 턴 중단 |
| Ctrl+F | 대화 검색 | 대화 검색 |

대기 중인 메시지는 입력창 바로 위에 늘어선다. 나가기 직전까지 이렇게 할 수 있다.

- **편집** — 앞 턴의 결과를 보고 나서 후속 메시지를 다시 쓴다
- **순서 변경** — 끌어서 옮기거나 맨 위로 올린다
- **병합** — 위 항목에 합친다. 계속 누르면 여러 개가 하나로 접힌다
- **지금 보내기**, 하나만 삭제, 전체 비우기

앱을 닫았다 열어도 대기열은 그대로 있다.

## 그 밖에

**엔진 둘을 한 창에서.** 스레드는 Claude Code나 OpenAI Codex 위에서 돈다. 새 대화는 다른 엔진을 고르기 전까지 Claude로 시작하고, 그 뒤로는 마지막에 고른 엔진으로 시작한다(스레드의 엔진을 바꾼 것도 포함). 마지막에 고른 모델·추론 강도·권한 모드도 새 스레드에 이어진다(모델과 추론 강도는 엔진별). 어느 엔진이든 대기열·조종·승인·모델과 추론 강도 선택·플랜 사용량·알림이 똑같다. 대화 도중에 **엔진을 바꿔 이어 갈** 수도 있다.

**정리되는 스레드 목록.** 프로젝트에는 원하는 대화를 직접 묶고, 머리글을 끌어 순서를 바꾼다. 프로젝트에 넣지 않은 대화는 미분류로 모인다. 사이드바 머리글의 깃발을 누르면 우선순위 보기로 바뀐다. AI가 제목과 최근 대화 내용을 읽고 중요성·긴급성·선행 작업·사용자의 우선 요청을 판단하고, 최근 7일을 우선순위 묶음 하나와 오늘·요일별 묶음으로 같은 순서에 따라 보여 준다. AI 정리는 제목과 폴더 이름만 읽고 주제별 그룹을 제안한다. 우선순위는 화면에 떠 있는 동안 메시지를 보내면 갱신되고, 평가가 실패하면 잠시 뒤 스스로 다시 시도하며, 직접 다시 평가할 수도 있다. 우선순위 보기에서 바로 새 대화를 시작할 수 있다. 사이드바 경계를 드래그해 너비를 조절하면 다음 실행에도 유지된다.

**깔끔하게 읽히는 대화.** 사이드바 아래의 토글로 도구 단계(명령 실행·파일 읽기·편집)와 생각 요약을 보이거나 숨긴다. 답변은 그대로 보인다. 작업을 숨긴 채 턴이 돌 때는 답이 나오기 전까지 '작업 중입니다…' 한 줄만 보인다. 끝난 턴 아래에는 작업 시간과 완료 시각이 뜬다. 보낸 메시지에 마우스를 올리면 그 메시지를 다시 실행할 수 있다(턴이 도는 중이면 대기열로 간다). 엔진의 백그라운드 작업 알림은 내가 쓴 메시지가 아니라 한 줄 알림으로 보인다.

**스레드 뒤의 폴더 열기.** 대화를 오른쪽 클릭하면 대화 기록 폴더나 작업 폴더를 파일 탐색기로 연다.

**대화를 잃지 않는 프로젝트 삭제.** 프로젝트의 … 메뉴나 오른쪽 클릭 메뉴에서 확인을 거쳐 묶음만 지운다. 대화는 미분류로 돌아가고 파일은 건드리지 않는다. 스레드를 지우면 엔진 쪽에서도 지워지고(Codex 스레드 포함) 다시 살아나지 않는다.

**대화별 초안.** 스레드를 오가도 앱을 켜 둔 동안에는 각 스레드의 보내지 않은 글과 첨부 이미지가 그대로 돌아온다.

**보이는 권한.** 승인 요청이 대화 안에 카드로 뜬다. 한 번 허용 / 항상 허용 / 거부, 그리고 스레드별 권한 모드(기본, 편집 허용, 계획, 우회).

**로컬 영상.** `[제목](clip.mp4)` 또는 `![제목](clip.mp4)`로 연결한 로컬 영상을 대화와 파일 미리보기에서 재생한다. 재생·구간 이동·음량·전체 화면을 지원하며 자동 재생하지 않는다. 절대 경로와 작업 폴더 기준 상대 경로를 쓸 수 있고, 공백이 있는 경로는 `<...>`로 감싼다. MP4/M4V·WebM·MOV·OGV를 인식하며 실제 재생 가능 여부는 운영체제의 코덱 지원에 따른다.

**이미지와 다이어그램.** 입력창에 붙여 넣거나 끌어다 놓으면 대기·조종 메시지에도 그림이 따라간다. 답변의 `mermaid` 블록은 다이어그램으로, `svg` 블록은 그림으로, 로컬 이미지 파일은 사진으로 보인다. Codex 스레드에서는 그림을 만들어 달라고 할 수도 있다. 한 메시지의 이미지와 영상은 확대 보기를 함께 쓴다. 방향키로 넘기고 Esc로 닫는다.

**닫힌 스레드까지 닿는 검색.** Ctrl+F로 제목과 대화 내용에서 찾는다. 열려 있지 않은 Codex 스레드도 걸린다.

**문서 안에서 찾기.** 문서 위에 마우스를 올리거나 포커스를 두거나 문구를 선택한 뒤 Ctrl+F를 누르면 문서 검색이 열린다. 선택한 문구가 검색어로 들어가고, 일치 항목 강조와 Enter·Shift+Enter 이동을 지원한다. Esc로 검색을 닫는다. 문서 밖에서는 기존 대화 검색이 열린다.

**빈 도구 오류 복구.** Claude로 엔진을 전환할 때 비어 있는 도구 오류에 설명을 채운다. 기존 기록의 잘못된 오류 결과도 원본을 백업한 뒤 다시 연결하기 전에 보정한다. Codex는 계정 전환으로 누락된 기록 인덱스를 복원하고 포크 이전의 대화도 유지한다.

**대화는 tiller가 따로 보관한다.** 모든 스레드를 내 디스크의 볼트에 복사해 둔다. 그래서 스레드가 즉시 열리고, 엔진이 자기 파일을 정리해도 대화가 남는다. Claude Code가 지운 트랜스크립트는 이어 가기 전에 제자리에 돌려놓고, Claude Code가 그 세션을 모른다고 하면 tiller가 가진 대화로 트랜스크립트를 새로 써서 이어 간다. [docs/vault.md](docs/vault.md)를 보면 된다.

**엔진별 여러 계정.** 사이드바의 **계정** 메뉴에서 **계정 추가**로 Codex·Claude 계정을 개수 제한 없이 더한다. 기존 계정은 그대로 남고 추가한 프로필은 재시작 뒤에도 유지된다. 공식 로그인을 마친 뒤 작업 사이에 계정을 고르면 되고, 기존 대화는 계속 쓸 수 있다. 메뉴에는 로그인 상태, 계정 이메일, 공식 엔진이 알려 주는 계정별 플랜 사용량(사용률과 초기화 시각)이 보인다. 사용량 확인은 모델에 프롬프트를 보내지 않고, 확인 실패는 로그인 상태와 따로 표시한다.

**전부 로컬이다.** 인증은 내 계정이나 API 키를 쓴다. 브라우저 로그인과 자격 증명 저장은 공식 엔진 프로세스가 로컬의 별도 프로필에서 맡고, 인증 캐시는 tiller의 대화 볼트에 넣지 않는다. 대화는 내가 고른 엔진으로만 보낸다.

**한국어·영어 UI.** 기본은 시스템 언어를 따른다.

## 현재 상태

tiller는 개발 중이고 **아직 인스톨러를 배포하지 않았다.** 릴리스는 이 저장소에 올라온다. 첫 배포 소식을 받으려면 [watch](https://github.com/miroqaan/tiller/subscription)를 걸어 두면 된다.

| 플랫폼 | 상태 |
|---|---|
| Windows | 개발 플랫폼. 풀린 패키지에서 확인함. 인스톨러는 아직 배포 전 |
| macOS | 아직 빌드·공증하지 않음 |
| Linux | AppImage 예정 |

인스톨러에는 엔진 둘이 함께 들어간다. 설치하면 따로 깔 것 없이 바로 쓸 수 있다. Claude Code 바이너리는 Anthropic이 발행한 그대로 나간다. 수정하지 않고, 다시 서명하지 않고, 로그인 수단을 빼지 않는다.

## 이슈와 요청

**여기가 그 자리다.** 버그 신고, 기능 요청, 질문 모두 [Issues](https://github.com/miroqaan/tiller/issues/new/choose)로 보내면 된다. 템플릿이 묻는 것은 처리에 꼭 필요한 몇 가지뿐이다(무엇을 했는지, 어느 엔진인지, 어느 버전인지).

앱 소스는 여기에 없다. tiller는 독점 소프트웨어이고 소스는 비공개 저장소에 있다. 이 저장소가 가진 것은 릴리스 다운로드, 이슈 트래커, 공개 문서다. `docs/` 문서에 대한 풀 리퀘스트는 환영한다.

이슈를 열기 전에 [기존 이슈](https://github.com/miroqaan/tiller/issues?q=is%3Aissue)를 한 번 훑으면 서로 한 왕복을 아낀다. 보안 문제로 보이는 것은 공개 이슈 대신 [SECURITY.md](SECURITY.md)의 절차를 따른다.

## 주의

- "권한 우회" 모드는 아무것도 묻지 않고 전부 실행한다. 프로젝트 밖 파일도 마찬가지다. 정말 필요할 때만 켠다.
- 선택 기능인 컴퓨터 조작 도구는 tiller가 도는 기기의 실제 마우스를 움직이고 실제 키보드를 누른다. 턴이 도는 동안 커서를 빼앗긴다고 생각하면 된다.

## 법적 고지

tiller는 개인 프로젝트이며 **Anthropic이나 OpenAI와 제휴·보증·후원 관계가 없다.** Claude와 Claude Code는 Anthropic의 상표이고 Codex는 OpenAI의 상표다. 각 엔진을 tiller로 쓰는 것에는 그 엔진의 약관이 그대로 적용된다.

앱은 독점 소프트웨어다. 이 저장소가 무엇을 다루는지는 [LICENSE](LICENSE)에 있다.
