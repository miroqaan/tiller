턴이 도는 중에 보낸 메시지는 **눈에 보이는 대기열**에 들어간다. 나가기 전까지 고치고, 순서를 바꾸고, 합칠 수 있다. **Tab**은 지금 도는 턴을 끊고 바로 보낸다.

![대기열에 후속 메시지 둘을 넣고, 하나를 고쳐 위 항목에 합친 뒤, Tab으로 턴을 끊고 새 답변이 끝나자 대기 메시지가 나가는 화면](docs/queue-steer.gif)

## 왜 만들었나

Claude Code CLI와 공식 데스크톱 앱은 에이전트가 바쁠 때 보낸 메시지를 둘 중 하나로 처리한다. 보이지 않는 대기열에 넣거나, 그 자리에서 턴을 끊거나. 무엇이 대기 중인지 보거나, 고치거나, 순서를 바꾸거나, 하나만 먼저 보낼 방법이 없다.

같은 요청이 Claude Code 이슈 트래커에 계속 올라온다.

- [anthropics/claude-code#92988](https://github.com/anthropics/claude-code/issues/92988) — 데스크톱 Code 탭에 "턴이 끝날 때까지 대기"가 없다
- [anthropics/claude-code#77537](https://github.com/anthropics/claude-code/issues/77537) — 대기열 UI: 항목을 보고, 지우고, 하나씩 넣기
- [anthropics/claude-code#30492](https://github.com/anthropics/claude-code/issues/30492) — 도구 호출 사이의 실시간 조종

tiller는 그 빈자리를 메우는 프런트엔드다. 에이전트를 대체하지 않고, 이미 쓰던 에이전트를 운전한다.

## 대기와 조종

| 키 | 대기 중 | 에이전트 작업 중 |
|---|---|---|
| Enter | 전송 | **대기열에 추가** |
| Tab | 전송 | **턴을 끊고 지금 보내기(조종)** |
| Shift+Enter | 줄바꿈 | 줄바꿈 |
| Esc (입력창이 빈 상태) | — | 지금 턴 중단 |
| Ctrl+F | 대화 검색 | 대화 검색 |

대기 중인 메시지는 입력창 바로 위에 늘어선다. 나가기 직전까지 이렇게 할 수 있다.

- **편집** — 앞 턴의 결과를 보고 나서 후속 메시지를 다시 쓴다
- **순서 변경** — 끌어서 옮기거나 맨 위로 올린다
- **병합** — 위 항목에 합친다. 계속 누르면 여러 개가 하나로 접힌다
- **지금 보내기**, 하나만 삭제, 전체 비우기

앱을 닫았다 열어도 대기열은 그대로 있다.

## 그 밖에

**엔진 둘을 한 창에서.** 스레드는 Claude Code나 OpenAI Codex 위에서 돈다. 어느 쪽이든 대기열·조종·승인·모델과 추론 강도 선택·플랜 사용량·알림이 똑같다. 대화 도중에 **엔진을 바꿔 이어 갈** 수도 있다.

**정리되는 스레드 목록.** 프로젝트를 직접 만들어 이름을 붙이고 대화를 넣는다. 프로젝트는 폴더가 아니라 내가 만든 묶음이라, 한 폴더의 대화를 서로 다른 프로젝트로 나눌 수도 있고 여러 폴더의 대화를 한 프로젝트에 모을 수도 있다. 넣지 않은 대화는 작업 폴더별로 묶인다. 아니면 작은 모델이 스레드 *제목*만 읽고(대화 내용은 읽지 않는다) 이름 붙은 그룹을 제안하게 한다. 고정, 이름 변경, 특정 메시지에서 포크, 프로젝트 이동.

**보이는 권한.** 승인 요청이 대화 안에 카드로 뜬다. 한 번 허용 / 항상 허용 / 거부, 그리고 스레드별 권한 모드(기본, 편집 허용, 계획, 우회).

**이미지와 다이어그램.** 입력창에 붙여 넣거나 끌어다 놓으면 대기·조종 메시지에도 그림이 따라간다. 답변의 `mermaid` 블록은 다이어그램으로, `svg` 블록은 그림으로, 로컬 이미지 파일은 사진으로 보인다. Codex 스레드에서는 그림을 만들어 달라고 할 수도 있다.

**닫힌 스레드까지 닿는 검색.** Ctrl+F로 제목과 대화 내용에서 찾는다. 열려 있지 않은 Codex 스레드도 걸린다.

**대화는 tiller가 따로 보관한다.** 모든 스레드를 내 디스크의 볼트에 복사해 둔다. 그래서 스레드가 즉시 열리고, 엔진이 자기 파일을 정리해도 대화가 남는다. Claude Code가 지운 트랜스크립트는 이어 가기 전에 제자리에 돌려놓는다. [docs/vault.md](docs/vault.md)를 보면 된다.

**전부 로컬이다.** 인증은 내 API 키이거나 이 기기에 이미 있는 Claude Code 로그인이다. tiller에는 로그인 화면이 없고, 우리 쪽 토큰을 저장하지 않으며, 대화를 내가 고른 엔진 말고 어디에도 보내지 않는다.

**한국어·영어 UI.** 기본은 시스템 언어를 따른다.

## 현재 상태

tiller는 개발 중이고 **아직 인스톨러를 배포하지 않았다.** 릴리스는 이 저장소에 올라온다. 첫 배포 소식을 받으려면 [watch](https://github.com/miroqaan/tiller/subscription)를 걸어 두면 된다.

| 플랫폼 | 상태 |
|---|---|
| Windows | 개발 플랫폼. 풀린 패키지에서 확인함. 인스톨러는 아직 배포 전 |
| macOS | 아직 빌드·공증하지 않음 |
| Linux | AppImage 예정 |

인스톨러에는 엔진 둘이 함께 들어간다. 설치하면 따로 깔 것 없이 바로 쓸 수 있다. Claude Code 바이너리는 Anthropic이 발행한 그대로 나간다. 수정하지 않고, 다시 서명하지 않고, 로그인 수단을 빼지 않는다.

## 이슈와 요청

**여기가 그 자리다.** 버그 신고, 기능 요청, 질문 모두 [Issues](https://github.com/miroqaan/tiller/issues/new/choose)로 보내면 된다. 템플릿이 묻는 것은 처리에 꼭 필요한 몇 가지뿐이다(무엇을 했는지, 어느 엔진인지, 어느 버전인지).

앱 소스는 여기에 없다. tiller는 독점 소프트웨어이고 소스는 비공개 저장소에 있다. 이 저장소가 가진 것은 릴리스 다운로드, 이슈 트래커, 공개 문서다. `docs/` 문서에 대한 풀 리퀘스트는 환영한다.

이슈를 열기 전에 [기존 이슈](https://github.com/miroqaan/tiller/issues?q=is%3Aissue)를 한 번 훑으면 서로 한 왕복을 아낀다. 보안 문제로 보이는 것은 공개 이슈 대신 [SECURITY.md](SECURITY.md)의 절차를 따른다.

## 주의

- "권한 우회" 모드는 아무것도 묻지 않고 전부 실행한다. 프로젝트 밖 파일도 마찬가지다. 정말 필요할 때만 켠다.
- 선택 기능인 컴퓨터 조작 도구는 tiller가 도는 기기의 실제 마우스를 움직이고 실제 키보드를 누른다. 턴이 도는 동안 커서를 빼앗긴다고 생각하면 된다.

## 법적 고지

tiller는 개인 프로젝트이며 **Anthropic이나 OpenAI와 제휴·보증·후원 관계가 없다.** Claude와 Claude Code는 Anthropic의 상표이고 Codex는 OpenAI의 상표다. 각 엔진을 tiller로 쓰는 것에는 그 엔진의 약관이 그대로 적용된다.

앱은 독점 소프트웨어다. 이 저장소가 무엇을 다루는지는 [LICENSE](LICENSE)에 있다.
